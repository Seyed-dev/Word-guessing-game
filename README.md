# Word Guessing Game 🎮

A modern web-based word guessing game focused on programming concepts.

## 📌 About The Project

This project is a programming-themed word guessing game where users try to guess the correct words related to web development and programming.

The goal of this project was to practice building interactive user interfaces and improving my JavaScript skills.

## ✨ Features

- 🎯 Score system
- ❤️ Lives system
- 📊 Score display for each question
- 📝 Current question tracking
- 🏁 Final results screen
- 📱 Responsive and modern UI

## 🛠 Technologies

- HTML5
- JavaScript
- Tailwind CSS
